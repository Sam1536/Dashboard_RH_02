# 👥 Dashboard de RH com Árvore de Decomposição | Power BI

Dashboard interativo de Recursos Humanos com os principais indicadores de pessoas: **funcionários ativos**, **contratações**, **demissões** e **turnover**, com uma **árvore de decomposição** para explorar o quadro de funcionários por área e cargo.

### Árvore de decomposição
Exploração dos funcionários ativos em níveis (área → cargo), mostrando onde o quadro está concentrado.


### Tooltips personalizados
Ao passar o mouse sobre os gráficos, aparece um detalhamento com o total de funcionários ativos, as horas extras por cargo e o salário.

## ✨ Recursos

- Indicadores de **Funcionários Ativos**, **Total de Contratações**, **Total de Demissões** e **% Turnover**
- Evolução das contratações por data
- Funcionários ativos por cidade (funil) e por gênero
- Árvore de decomposição por área e cargo
- Tooltips personalizados com horas extras por cargo e salário

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query · Visuais personalizados (gráfico de evolução e filtro)

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
